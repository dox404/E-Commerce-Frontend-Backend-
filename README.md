# E-Commerce (MERN)

Full-stack e-commerce project built with React (frontend) and Node/Express + MongoDB (backend).

## Structure

This repo uses git submodules:

| Folder      | Contents                          | Repository                                            |
| ----------- | --------------------------------- | ----------------------------------------------------- |
| `frontend/` | React client (Create React App)   | https://github.com/dox404/E-commerce_Frontend.git     |
| `Backend/`  | Express API + MongoDB             | https://github.com/dox404/E-commerce_Backend.git      |

## Getting started

```bash
git clone --recurse-submodules https://github.com/dox404/E-Commerce-Frontend-Backend-.git
```

### Frontend

```bash
cd frontend
npm install
npm start
```

### Backend

```bash
cd Backend
npm install
npm run dev   # or: node server.js
```
